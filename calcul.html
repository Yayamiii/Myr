Le programme verif_S.py certifie chaque chiffre de la preuve en arithmétique de boules (bibliothèque Arb) : chaque nombre est encadré, chaque arrondi est compté. Il part de rationnels exacts, lus dans certificat_S.json.

Pour le rejouer : Python 3, puis pip install python-flint, puis python verif_S.py dans le dossier des deux fichiers. Chaque ligne « OK » est une inégalité établie avec un encadrement rigoureux.
