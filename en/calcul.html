The program verif_S.py certifies every figure of the proof in ball arithmetic (the Arb library): every number is enclosed, every rounding is accounted for. It starts from exact rationals, read from certificat_S.json.

To replay it: Python 3, then pip install python-flint, then python verif_S.py in the folder holding both files. Each line marked OK is an inequality established with a rigorous enclosure.
